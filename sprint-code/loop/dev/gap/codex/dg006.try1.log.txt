## How to run these

Run them as **separate passes**, not as one read-through. Each family hides from whatever pattern
caught the previous one: a scan tuned to em dashes will not see a disguised not-X-but-Y, and a
scan for self-reference will not see self-congratulation, because the latter never uses the word
"arc". Rules 3 to 6 in particular were each found only after the one before it had been cleared.

A narration-read pass (reading aloud or TTS) catches a family the pattern scans miss: sentences
that parse but stumble when spoken, same-word chains, and ornament qualifiers. Liezl's
read-aloud edits are the calibration source for that pass; fold her corrections back into these
rules rather than treating them as one-offs.
