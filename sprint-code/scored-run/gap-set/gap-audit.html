Gap set audit: 10 cases

For each case, read the records and decide whether they settle where each report's information comes from. A firsthand root is a record whose named maker saw or measured the event. If any report's trail runs out (a missing record, no maker, hearsay, no source, or two records that may be one observation), choose "No". Your answers save in this browser.
